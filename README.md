# 📧 Gmail Clone

A **Gmail Clone** built with **Node.js, MongoDB, React, and Tailwind CSS**, designed to replicate core email functionalities like sending, receiving, organizing, and managing emails with a modern and responsive UI.

---

- 🔹 **User Authentication** (Sign Up / Login with JWT)
- 🔹 **Compose, Send, and Receive Emails**
- 🔹 **Email Sending via EmailJS** for real-time email delivery
- 🔹 **Inbox, Sent, Drafts, and Trash Folders**
- 🔹 **Search and Filter Emails**
- 🔹 **Responsive Design** with Tailwind CSS
- 🔹 **Scalable Backend** with Node.js & MongoDB
- 🔹 **Modern UI** inspired by Gmail

---

## 🛠️ Tech Stack
**Frontend:** React, Tailwind CSS  
**Backend:** Node.js, Express.js  
**Database:** MongoDB (Mongoose ORM)  
**Email Service:** EmailJS  
**Others:** REST APIs, Context API / Redux
